# معايير الشيفرة

> يعتمدها `cto`.

## Python / Django
- PEP 8، وأداة التنسيق ruff.
- منطق الأعمال في الخدمات أو النماذج، لا في الـ Views.
- تجنب N+1: `select_related` و`prefetch_related`.
- كل واجهة API لها صلاحيات صريحة (`permission_classes`).

## React
- ESLint، مكونات دالية وHooks.
- الاتجاه RTL افتراضياً، ونصوص الواجهة قابلة للترجمة.

## قاعدة البيانات
- أسماء الجداول والأعمدة بالإنجليزية snake_case، بطول لا يتجاوز 30 حرفاً (حد Oracle).
- كل تغيير عبر Migration، ولكل Migration عكسها.

## Git
- فرع لكل ميزة، ورسائل commit واضحة، ولا أسرار في المستودع.
